- レビューで受け入れた判断：信頼度は自動判定に（entrance-house と studio-bedside は高、studio-desk は低に変わった）、帯の下に AI 生成の注記を残す、座って見る壁は「座ったときの目の高さ」と書く。残った課題：終わりの一文が縦画面で切れたドアを指すことがある（次回、縦画面では 2 つ目の比較を使う）

- 作家の決定で「部屋で見る」を 2 種類（一人暮らしの部屋、広い家のリビング）× 2 枚に。帯のキャプションは「種類 ─ 場所」、比較の一文は拡大表示だけ。F15 を一人暮らしの机の上とベッド脇にも置いた（小さい部屋では壁の 4 割を占め、大きさが伝わる）。Sonnet 実装、Fable レビュー（ラベルの重複を直し、机の部屋の交差確認を手前のノート PC から壁際のランプに変えて信頼度を中に）
- ドアの高さ 200 cm への疑問：新しい住宅では 2,000 mm が標準、古い住宅は 1,800〜1,900 mm。185 cm なら絵は 8% 大きいのが正しいが、見た目では区別がつかない。画像を作り直しても不確かさは消えない。人（身長 160 cm）が写った版を種類ごとに 1 枚足す案を提案中

- 流体の質感（`docs/FLUID_LOOK.md` 段階 1〜2）と「渦に吸い込まれる」入りを Opus が実装、Fable がレビュー。厚みの場（`relief.png` を初期値に、流れと一緒に移流、収束で盛り上がる）、法線からの陰影（稜線の近くだけ）、サテンの小さな鏡面、薄い窓の光、ブルーム、粒子、周辺減光。入りは T1〜T2 を 3 秒に統合（縁がほどけ、最明色の重心に渦、渦の中心へ拡大、6° の回転、周辺減光）。VR は S1〜S3 を 5 秒に重ねた。追加パス 4
- レビューでの調整：渦で色が混ざって彩度が落ちていたので渦の強さを 0.5 → 0.2、ブルームと窓の光を半分、原画への回帰を 0.014、彩度の補正を 0.45 に。12 秒・20 秒のフレームで鮮やかさが戻ったことを確認
- 事故：Opus の作業中に Fable が `git add -A` でコミットしたため、コミット `aaa2ee8`（メッセージは「部屋のプロンプト」）に質感の実装の大半が混ざった。内容は失われていない。以後、エージェントが作業中は `git add` にパスを指定する

**決めた**

- 大きなうねりは中くらいの大きさで弱く（周波数 4、0.18）。原画への回帰は 0.005。流れ続けると 90 秒で色が混ざって茶色くなるので、`restore` / `drive` / `speed` は作家が詰めるダイヤルとして `overrides` に
